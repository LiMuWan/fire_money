# 迭代 17 - 按钮路由与页面映射

## 目标

- 保证主界面第一屏所有核心按钮都可点击，并且点击后有明确页面或区域响应。
- 把首页按钮、推荐页按钮、策略按钮的职责边界梳理清楚，避免“按钮只是样式入口”。
- 为后续继续扩展独立页面、盘中提醒面板和策略详情页建立统一导航规范。

## 用户价值

- 用户第一次打开软件时，不会再遇到“看起来能点，但点了没有反应”的入口。
- 首页可以承担总控台职责，推荐页承担策略工作台职责，两者之间的跳转更顺手。
- 战法筛选、题材热度、交易决策等核心入口，能直接把用户带到对应功能区域。

## 本轮范围

### 1. 顶部主标签页

- `龙头主控台`：市场总览、龙头池、涨跌分布、资金方向、题材热度、交易决策总控。
- `策略扫描`：本地股票池扫描、参数优化、观察池维护。
- `每日推荐`：题材榜、龙头榜、每日推荐池、五大战法工作台、交易计划、持仓建议。
- `打板监控`：回封观察、炸板风险、强势连板候选。
- `配置`：策略参数、授权配置、报告模板、关注题材、自动导出。
- `统一登录`：渠道账号、SDK 接入、登录参数保存。
- `明细复盘`：单标的回测、明细回放、导出复盘日报。
- `交易执行`：账户概览、订单计划导出、执行记录。

### 2. 首页快捷按钮

- `市场总览`：回到首页总览视图，优先聚焦市场代理走势。
- `龙头池`：跳转到每日推荐页并定位每日推荐股票池。
- `涨跌分布`：保留在首页，聚焦左侧涨跌分布/新闻流。
- `资金方向`：保留在首页，聚焦右侧主力控盘/资金画像。
- `题材热度`：跳转到每日推荐页并定位题材热度榜。
- `交易决策`：跳转到每日推荐页并定位今日交易计划。

### 3. 首页策略筛选按钮

- `全部 / 龙头模型 / 主力雷达 / 擒龙打板 / 价值低吸 / 掘龙决策`
- 职责：
  - 过滤首页算法池。
  - 同步推荐页战法明细的当前策略。
  - 在状态栏上显示当前策略上下文。

### 4. 首页时间周期按钮

- `分时 / 1分 / 5分 / 15分 / 30分 / 60分 / 日线`
- 职责：
  - 真正切换图表标题与图像展示上下文。
  - 调整图表区高度，保证短周期和日线周期都有合理可视面积。

## 实现原则

- 首页按钮允许“切页”或“切区”，但必须给用户明确视觉反馈。
- 推荐页承担策略工作台职责，因此涉及龙头池、题材热度、交易计划的入口，优先路由到推荐页。
- 同一类策略入口必须共享同一套状态来源，避免首页和推荐页显示不一致。

## 验收标准

- 第一屏可见按钮点击后，必须发生以下之一：
  - 切换到对应页面。
  - 切换到对应区域并改变布局焦点。
  - 触发真实业务动作。
- 时间周期按钮不能再只是静态样式。
- 首页策略筛选与推荐页战法明细必须联动。
- 顶部标签切换后，页面徽标或状态文案需反映当前工作区。

## 风险与后续

- 首页按钮逐渐具备“导航”能力后，要避免和顶部标签页形成重复认知，因此后续应继续精简说明文案。
- 后续建议继续拆分以下页面：
  - 独立题材页面
  - 独立龙头页面
  - 独立盘中提醒页面
  - 独立交易决策页面
