# 迭代 07 - 五策略产品化与首页主控台重构

## 目标
- 把“龙头模型、主力雷达、擒龙打板、价值低吸、掘龙决策”从按钮名升级成真实可计算、可解释、可展示的五个策略能力。
- 让推荐池、盘前计划、首页市场主控台使用同一套策略评分，不再出现“有菜单无功能”。
- 把首页右侧榜单升级为真正的卡片组件，并重新分配首页空间比例，让图表、表格和滚动区域更可读。

## 用户价值
- 用户可以清楚知道一只股票为什么属于“龙头模型”还是“价值低吸”，并看到对应策略分数。
- 每日股票池不再只有总分，而是可以回答“为什么今天这只更适合打板，那只更适合低吸”。
- 首页更像专业看盘终端，重点信息一屏可读，不再被过小的滚动区和纯文本区域挤压。

## 五策略定义

### 龙头模型
- 目标：识别主线题材中的高辨识度前排。
- 核心指标：
  - 技术强度
  - 持续性
  - 龙头属性
  - 位置合理性
  - 消息确认
- 输出：
  - `leader_model_score`
  - 主选策略候选

### 主力雷达
- 目标：识别资金主动性更强、主力净流入更明确的标的。
- 核心指标：
  - 消息面
  - 位置
  - 龙头属性
  - 资金标签语义
  - 技术强度
- 输出：
  - `main_force_score`
  - 资金驱动型解释

### 擒龙打板
- 目标：识别更适合板上确认、回封确认、强一致加速的标的。
- 核心指标：
  - 技术强度
  - 持续性
  - 龙头属性
  - 打板语义偏置
  - 位置是否接近强势区
- 输出：
  - `board_attack_score`
  - 打板触发风格

### 价值低吸
- 目标：识别适合分歧低吸、回踩修复、低位承接的标的。
- 核心指标：
  - 位置分
  - 技术分
  - 持续性
  - 消息面
  - 低吸语义偏置
- 输出：
  - `value_recovery_score`
  - 修复型理由

### 掘龙决策
- 目标：把前四类策略综合成最终动作建议。
- 核心指标：
  - 四类策略分
  - 技术面
  - 位置
  - 持续性
  - 消息面
- 输出：
  - `dragon_decision_score`
  - `primary_strategy`
  - 推荐动作解释

## 数据流
1. 本地扫描/远程市场筛选产生原始候选。
2. 推荐引擎生成技术、位置、持续性、消息、龙头基础分。
3. 五策略评分器生成五个策略分与主选策略。
4. 题材热度引擎叠加题材、龙头等级与主线排序。
5. 决策引擎基于主选策略生成盘前动作、止损、目标和仓位说明。
6. 首页主控台展示卡片榜、市场代理走势、资金/决策面板。

## 首页改造要求
- 右侧掘龙榜改为自定义 Qt 卡片组件，不再使用 `QTextEdit + HTML` 模拟。
- 中部图表区、股票池表格扩大。
- 左侧文本区压缩到只保留必要摘要。
- 顶部快捷按钮、过滤按钮、指标卡统一配色、边距、圆角和高度。

## 验收标准
- 推荐池中的每条 `RecommendationRow` 都拥有五类策略分和 `primary_strategy`。
- 首页筛选“龙头模型 / 主力雷达 / 擒龙打板 / 价值低吸 / 掘龙决策”时，结果来自真实策略字段。
- 交易计划中的理由会包含主选策略，而不是只有总分。
- 右侧榜单为真实卡片组件，可显示 3 张卡。
- 首页图表和表格区域明显扩大，滚动区内容不再被截断。
