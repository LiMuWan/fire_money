# 迭代 02：题材热度与龙头识别

## 1. 迭代目标

在 MVP 已具备“每日股票池 + 建仓计划 + 持仓建议”的基础上，补上题材热度和龙头识别，让系统从“会挑票”升级为“先选方向，再选票”。

本次迭代重点解决三个问题：

1. 今天最强的是哪个方向。
2. 这个方向里谁是龙头、谁是跟风、谁只是噪声。
3. 每日股票池如何优先保留主线题材中的高辨识度标的。

## 2. 用户价值

- 降低“个股没问题、方向错了”的误判。
- 提升盘前计划的可解释性和盘中跟踪效率。
- 让界面更接近成熟商业化看盘产品的主线视角。

## 3. 范围

### 3.1 必做

- 题材热度排行榜
- 题材持续性评分
- 龙头股识别
- 每日股票池增加“所属题材”和“龙头标签”
- 盘前报告增加“今日主线题材”和“龙头观察”

### 3.2 可选

- 题材扩散图
- 题材轮动历史
- 题材联动关系图

## 4. 核心需求

### 4.1 题材热度引擎

输入：

- 题材内个股涨跌幅
- 题材内涨停家数
- 题材成交额变化
- 新闻催化强度
- 过去 3 到 5 日延续情况

输出：

- `theme_name`
- `theme_strength_score`
- `theme_continuation_score`
- `theme_news_score`
- `theme_rank`
- `theme_risk_flag`

### 4.2 龙头识别引擎

识别原则：

- 题材内涨幅领先
- 市场辨识度高
- 成交额和换手支持持续交易
- 新闻和资金催化更集中
- 在题材内具备明显带动性

输出：

- `leader_level`
- `leader_score`
- `leader_reason`

建议分级：

- `CORE_LEADER`：核心龙头
- `ACTIVE_LEADER`：活跃龙头
- `FOLLOWER`：跟风股
- `NOISE`：噪声标的

### 4.3 股票池升级

股票池新增字段：

- 所属题材
- 题材热度分
- 龙头等级
- 是否主线题材
- 题材内排名

排序逻辑升级建议：

```text
total_score =
  市场情绪分 * 15%
  + 题材热度分 * 20%
  + 龙头分 * 15%
  + 技术分 * 20%
  + 资金分 * 15%
  + 消息分 * 10%
  - 风险扣分 * 5%
```

### 4.4 盘前计划升级

新增版块：

- 今日主线题材 Top 5
- 题材风险提示
- 每个主线题材对应龙头股
- 从主线题材中筛出的可交易股票池

## 5. 页面设计

### A 区：市场全局

- 情绪分
- 市场周期
- 风险等级

### B 区：题材热度榜

- 题材名称
- 热度分
- 持续性
- 新闻强度
- 龙头数量

### C 区：龙头股榜

- 股票名称
- 所属题材

- 触发信号

- 只保留通过题材层过滤后的股票

## 6. 技术实现建议

### 6.1 数据结构

建议新增：

- `ThemeHeatRow`
- `LeaderCandidate`
- `ThemeSnapshot`

### 6.2 模块拆分

- `quant_hunter/theme.py`
  负责题材热度计算和排名。
- `quant_hunter/leader.py`
  负责龙头识别和分级。
- `quant_hunter/recommend.py`
  聚合题材分与龙头分，更新股票池排序。
- `quant_hunter/reports.py`
  在盘前计划中新增题材和龙头摘要。
- `app_qt.py`
  新增题材热度表和龙头榜面板。

### 6.3 数据来源

MVP 可先使用：

- 本地题材映射 CSV
- 新闻标题规则分类
- 成交额和涨跌幅统计

后续再升级到更高质量的实时题材数据。

## 7. 验收标准

1. 系统能输出题材热度 Top 5。
2. 每只股票池标的都能显示所属题材和龙头等级。
3. 龙头股榜能展示至少 1 个可解释原因。
4. 盘前 Markdown 报告中新增主线题材和龙头摘要。
5. 股票池排序会受到题材热度和龙头等级影响。

## 8. 风险

- 没有稳定题材映射时，题材归属会抖动。
- 新闻分类质量不足时，题材热度会失真。
- 龙头识别过于依赖涨幅时，容易把情绪股误判为核心龙头。

## 9. 与商业化的关系

这一迭代是商业化展示能力的关键节点。用户付费时，往往不是只为一个买卖点，而是为“市场主线判断 + 龙头识别 + 每日交易计划”的整套工作流买单。
