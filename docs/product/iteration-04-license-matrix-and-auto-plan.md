# 迭代 04 - 授权矩阵、关注题材加权与自动盘前报告

## 目标

把产品从“可研究”继续推进到“可售卖”，让不同版本的能力边界开始真实生效，并让关注题材从展示信息升级为排序输入。

## 本次迭代范围

### 1. 授权矩阵

- 增加 `TRIAL / PRO / ENTERPRISE` 三档本地授权状态。
- 界面中明确显示不同版本的能力差异。
- 功能差异要落到真实行为：
  - `TRIAL`
    - 保留手动研究与手动导出流程
    - 不开放自动盘前报告
  - `PRO`
    - 开放自动盘前报告
    - 关注题材获得更高排序权重
  - `ENTERPRISE`
    - 在 `PRO` 基础上开放更强的题材加权
    - 扩展题材榜与龙头榜展示数量

### 2. 关注题材加权

- `focus_themes` 不再只是展示字段。
- 推荐引擎在生成每日股票池时，对命中关注题材的标的增加额外分值。
- 加权结果要体现在：
  - 每日股票池排序
  - 盘前交易计划
  - 题材热度与龙头跟踪

### 3. 自动盘前报告

- 本地自动盘前计划导出链路上线。
- 仅在授权允许且用户开启后生效。
- 默认在盘前时间窗内执行一次，避免重复导出。

## 实现说明

- `quant_hunter/recommend.py`
  - 增加 `focus_themes` 与 `focus_theme_boost`
- `quant_hunter/storage.py`
  - 持久化 `auto_daily_plan_export`
- `app_qt.py`
  - 新增企业版本地切换
  - 新增自动盘前报告开关
  - 用授权矩阵驱动界面开关与题材面板容量
  - 盘中刷新时自动检查是否需要导出盘前计划

## 验收标准

- 关注题材在相同基础分下会获得更高排序。
- `TRIAL` 无法开启自动盘前报告。
- `PRO / ENTERPRISE` 可以开启自动盘前报告。
- 自动盘前报告同一天只导出一次。
- 应用重启后，授权状态与自动导出开关会恢复。

## 后续建议

- 接入真正的授权服务与机器绑定。
- 把自动导出扩展为定时任务中心。
- 给企业版增加团队席位、共享题材库与统一报表模板。
