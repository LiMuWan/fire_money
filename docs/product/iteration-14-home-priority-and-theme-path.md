# 迭代 14 - 首页优先级与主线推演路径

## 目标
- 让首页和推荐页都具备统一的“先看什么”能力。
- 把题材、龙头、个股、动作之间的关系用更直观的路径方式展示出来。

## 本次交付
- 首页新增 `盘前优先级` 面板。
- 推荐页新增 `主线推演路径` 面板。
- 首页和推荐页都能展示：
  - 市场层
  - 主线层
  - 策略层
  - 个股层

## 用户价值
- 打开首页先看大局，切到推荐页再看路径和动作，信息层级更清晰。
- 更接近专业终端里的“先大后小、先主后次”的盯盘方式。

## 验收标准
- 首页指标区下方存在盘前优先级面板。
- 推荐页能看到题材 -> 龙头 -> 个股 -> 动作的主线推演路径。
