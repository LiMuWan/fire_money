# 迭代 08 - 五大战法工作台与推荐页展开

## 目标
- 把五大战法从首页摘要继续展开到推荐页，形成可运营、可讲解、可演示的工作台。
- 让推荐页不只是“股票池表格”，而是能展示每套策略的头号候选、前 3 候选和逻辑摘要。
- 强化 `主策略 -> 交易动作 -> 止损止盈` 的链路一致性。

## 本次新增
- 推荐页新增 `五大战法工作台`
  - 龙头模型
  - 主力雷达
  - 擒龙打板
  - 价值低吸
  - 掘龙决策
- 每日推荐股票池新增主策略与五类评分列。
- 决策层补充策略差异化止损止盈测试。

## 交互变化
- 首页负责总览、榜单、主图、资金与决策摘要。
- 推荐页负责深挖五大战法。
- 用户可以从推荐池直接看出：
  - 这只股票属于哪种打法
  - 该打法下它的相对排名
  - 为什么被归为该打法

## 验收标准
- 推荐页存在五大战法工作台区域。
- 每个战法卡片都能显示：
  - 主打法命中数量
  - 头号候选
  - 前 3 候选
  - 简短逻辑摘要
- 推荐池表格可直接看到主策略和五类评分。
- 单元测试覆盖策略差异化止损止盈。
