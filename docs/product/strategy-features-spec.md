# 五大战法产品需求说明

## 目标
- 把 `龙头模型`、`主力雷达`、`擒龙打板`、`价值低吸`、`掘龙决策` 从展示型按钮升级为可计算、可筛选、可解释、可落到交易计划的真实能力。
- 统一这五套能力在 `首页主控台`、`每日推荐`、`盘前计划`、`持仓建议` 里的输出口径。
- 让用户一眼看到每只股票属于哪种打法、为什么入选、当前应该建仓还是观察。

## 共用输入
- 行情输入：最新价、涨跌幅、换手率、成交额、主力净流入、热度分。
- 技术输入：技术分、位置分、持续性分、信号标签、突破/回补/趋势状态。
- 题材输入：题材名、题材热度、题材排名、龙头级别。
- 消息输入：新闻催化、公告摘要、情绪分。
- 用户输入：关注题材、版本能力、仓位上限、主线前 N 约束。

## 功能一：龙头模型
### 业务目标
- 找出主线题材里的核心龙头、活跃龙头、潜在补涨龙。

### 核心规则
- 技术强度高。
- 持续性高。
- 龙头属性明确。
- 题材热度靠前。
- 消息面不是明显拖累。

### 输出
- `leader_model_score`
- `primary_strategy` 可能被标为 `龙头模型`
- 首页榜单可按龙头模型排序
- 盘前计划给出更偏趋势持有的止损止盈

## 功能二：主力雷达
### 业务目标
- 找出主力净流入清晰、机构或游资动作明显、适合跟随资金方向的标的。

### 核心规则
- 主力净流入显著。
- 成交额与换手率匹配，不是无量异动。
- 消息催化和资金标签匹配。
- 技术面至少不破坏。

### 输出
- `main_force_score`
- `primary_strategy` 可能被标为 `主力雷达`
- 首页右侧资金画像重点显示
- 交易建议更强调“强势跟随”而不是“低位埋伏”

## 功能三：擒龙打板
### 业务目标
- 找出更适合强势确认、回封确认、打板跟进的股票。

### 核心规则
- 技术强度高。
- 持续性强。
- 位置处于强势区而不是深度透支区。
- 语义上存在涨停、连板、回封、打板等特征。

### 输出
- `board_attack_score`
- `primary_strategy` 可能被标为 `擒龙打板`
- 决策层使用更紧止损和更进攻目标位
- 首页筛选按钮可单独查看打板型股票池

## 功能四：价值低吸
### 业务目标
- 找出适合回踩修复、低位承接、分歧低吸的股票。

### 核心规则
- 位置分高于技术冲动分。
- 回踩后仍保留趋势基础。
- 存在修复、回补、低位、低吸等语义特征。
- 不属于纯弱势下跌。

### 输出
- `value_recovery_score`
- `primary_strategy` 可能被标为 `价值低吸`
- 决策层使用更宽容的止损和偏稳健目标位
- 首页“强承接席位”与“高博弈风险席位”更适合辅助判断

## 功能五：掘龙决策
### 业务目标
- 汇总前四大战法，给出最终动作建议和交易解释。

### 核心规则
- 组合龙头、资金、打板、低吸四类得分。
- 同时参考技术分、位置分、持续性分、消息分。
- 受市场情绪、题材热度、主线前 N 约束。

### 输出
- `dragon_decision_score`
- `primary_strategy`
- 推荐动作、计划买点、止损、目标
- 持仓建议中的加仓、减仓、离场逻辑

## 首页主控台需求
- 顶部按钮只保留一套导航，不再重复堆叠。
- 第一屏优先级：图表 > 榜单卡片 > 股票池表格 > 文本说明。
- 右侧榜单必须为真实 Qt 卡片组件，不再依赖 `QTextEdit + HTML`。
- 左侧文本面板控制在摘要级，不占用大面积空间。
- 股票池表格和 K 线区域要明显大于纯文本区域。

## 验收标准
- 每条 `RecommendationRow` 都带五类策略分和 `primary_strategy`。
- 首页筛选 `龙头模型 / 主力雷达 / 擒龙打板 / 价值低吸 / 掘龙决策` 时，结果来自真实字段。
- 右侧榜单卡片能展示 `TOP 1 / TOP 2 / TOP 3`，并显示主策略、资金标签、热度、涨幅、净流入。
- 右侧决策面板能看到主策略和五策评分。
- 交易计划中的止损、目标与主策略相匹配。
