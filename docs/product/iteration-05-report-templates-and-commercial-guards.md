# 迭代 05 - 报告模板与商业化能力边界

## 目标

把产品从“有授权状态”推进到“不同版本能力真实不同”，并让盘前计划开始支持模板化输出。

## 本次迭代内容

### 1. 版本能力边界

- `TRIAL`
  - 保留手动研究、手动导出。
  - 自动盘前报告关闭。
  - 市场历史回看深度、监控摘要容量、盘前股票池导出深度较低。
- `PRO`
  - 开放自动盘前报告。
  - 提高关注题材加权。
  - 扩大历史回看深度与报告导出深度。
- `ENTERPRISE`
  - 在 `PRO` 基础上进一步提高关注题材加权。
  - 扩大题材面板、监控摘要与盘前导出深度。

### 2. 盘前报告模板

- 支持 `balanced / focus / aggressive / defensive` 四种模板。
- 支持“仅输出关注题材股票”。
- 支持自定义盘前股票池展示上限。
- 模板配置会进入本地状态并影响 Markdown / JSON 导出结果。

### 3. 商业化落地方式

- 版本能力通过统一授权能力函数下发，而不是散落在各个界面里。
- 市场页历史回放深度、盘前导出深度、监控摘要容量都通过授权能力控制。
- 为后续接入真实授权服务保留清晰的能力映射层。

## 实现位置

- `quant_hunter/storage.py`
  - 新增报告模板、关注题材过滤、盘前导出深度配置持久化。
- `quant_hunter/reports.py`
  - 新增盘前报告模板过滤与导出深度控制。
- `app_qt.py`
  - 配置页新增模板与导出参数。
  - 授权能力开始真实限制市场回放深度、盘前导出深度和监控摘要容量。

## 验收标准

- 切换报告模板后，盘前计划导出的股票池顺序或过滤结果发生变化。
- 启用“仅输出关注题材股票”后，盘前计划中只保留命中关注题材的股票。
- 不同授权版本下，市场历史回看深度与盘前导出上限不同。
- 所有配置在应用重启后可恢复。

## 后续建议

- 接入正式授权服务和套餐计费。
- 将模板升级为可编辑模板，而不只是内置模板。
- 允许企业版定义团队级共享模板与统一导出格式。
