# 量化智投商业化路线图

## 1. 产品定位

产品定位为面向 A 股活跃交易者的桌面量化交易助手，核心价值是：

- 每日自动生成可交易股票池。
- 结合市场情绪、题材热度和个股结构给出动作建议。
- 把建仓、加仓、减仓、离场流程做成可解释、可风控、可复盘的工作台。

参考你给出的截图，目标不是简单复刻一个“看盘软件”，而是做一个“决策工作台”：

- 左上是大盘与情绪总览。
- 中上是涨跌分布、板块热度、市场周期。
- 右侧是龙头/核心股榜单和 AI 解读。
- 下方中间是每日股票池与持仓动作台。
- 下方左侧是新闻、公告、催化摘要。

## 2. 用户分层

### 2.1 个人专业版用户

- 目标：每天快速得到可交易标的与动作建议。
- 关注：速度、稳定性、解释性、能不能落地执行。

### 2.2 工作室/小团队

- 目标：统一研究流程，沉淀策略与复盘。
- 关注：账号权限、日志、报告导出、共享配置。

### 2.3 企业版客户

- 目标：接入私有数据、定制策略和部署。
- 关注：私有化、权限体系、审计、API 扩展能力。

## 3. 版本规划

### V0.1 最小原型

目标：每天输出一份可交易股票池和动作建议。

必须完成：

- 市场情绪评分
- 每日股票池
- 持仓建议
- 盘前计划 Markdown 输出
- 盘后复盘 Markdown 输出
- 本地桌面查看和人工确认

### V0.2 题材驱动版

目标：把“市场最强方向”正式纳入选股链路。

新增：

- 板块热度排行
- 龙头股识别
- 题材持续性评分
- 题材到个股的映射展示

### V0.3 交易工作台版

目标：从“看报告”升级到“在工作台上做决策”。

新增：

- 盘前、盘中、盘后三态面板
- 股票池分组
- 建仓/加仓/减仓/离场待办流
- 交易确认弹窗和日志

### V0.4 商业化试运行版

目标：可面向首批付费用户交付。

新增：

- 用户配置模板
- 订阅与授权
- 多数据源适配
- 更新机制
- 错误上报与帮助中心

### V1.0 商业正式版

目标：形成稳定售卖产品。

新增：

- 权限与审计
- 插件化指标
- 自定义风格模板
- 企业私有化部署
- API / SDK 对接

## 4. 商业化模块拆分

### 4.1 标准能力

- 日度股票池
- 情绪分析
- AI 解读
- 仓位建议
- 盘前盘后报告

### 4.2 增值能力

- 实时分时监控
- 专题题材库
- 机构版风险看板
- 多账户联动
- 自定义因子和策略

### 4.3 收费建议

- 基础版：日度股票池 + 情绪评分 + 报告导出
- 专业版：增加 AI 解读、持仓建议、回测和盘中刷新
- 企业版：增加私有化部署、权限、审计、定制数据源

## 5. 非功能需求

### 5.1 可解释性

- 所有建议必须可追溯到指标和规则。
- 每个动作必须附带理由和风险说明。

### 5.2 稳定性

- 数据拉取失败时允许降级使用缓存。
- 股票池生成任务必须可重复执行。

### 5.3 安全性

- 本地敏感配置加密存储。
- 交易执行前双重确认。
- 操作日志可导出。

### 5.4 合规性

- 默认以“研究辅助、人工确认”为主。
- 风险提示不可关闭。
- 不承诺收益，不暗示保本。

## 6. 核心任务流

### 6.1 盘前

- 汇总昨日市场情绪和隔夜消息。
- 生成今日题材优先级。
- 输出今日可交易股票池。
- 给出建仓候选和风险提示。

### 6.2 盘中

- 监控股票池内标的的触发条件。
- 更新是否可建仓、加仓或撤销。
- 对持仓给出减仓或离场提醒。

### 6.3 盘后

- 汇总当日信号命中率。
- 输出盘后复盘报告。
- 更新策略表现和次日观察名单。

## 7. 建议的技术实现路线

### 7.1 当前代码基础上演进

- 保留现有 `PySide6` 桌面壳。
- 扩展现有扫描和决策模块，不推倒重来。
- 报告输出统一进入 `exports` 目录。

### 7.2 后端逻辑分层

- 数据层：行情、新闻、板块、个股元数据。
- 因子层：情绪、题材、趋势、风险因子。
- 评分层：股票池打分、动作打分。
- 决策层：输出 BUILD / ADD / TRIM / EXIT。
- 解释层：面向用户的自然语言摘要。
- 展示层：桌面面板与 Markdown 报告。

### 7.3 自动任务

- 盘前任务：每天生成股票池。
- 盘后任务：每天生成复盘。
- 手动触发：用户随时重新刷新。

## 8. 成功指标

### 业务指标

- 日活和周留存
- 试用转付费率
- 报告打开率
- 股票池使用率

### 产品指标

- 股票池生成成功率
- 数据更新延迟
- AI 解读满意度
- 操作日志完整率

### 策略指标

- 股票池次日超额收益
- 建仓建议命中率
- 最大回撤控制
- 建议执行后的盈亏分布

## 9. 当前开发优先级

当前阶段优先级从高到低为：

1. 性能与稳定性
2. 状态透明化与错误恢复
3. 关键页面功能补全
4. 表格模型重构与更低内存占用
5. 更精细的商业化授权与交付能力
