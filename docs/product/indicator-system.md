# 量化智投指标体系

## 1. 产品目标

围绕 A 股日内到波段交易场景，构建一套可商业化、可解释、可审计的决策指标体系，用于回答四个问题：

1. 今天市场能不能做。
2. 今天应该做哪个方向。
3. 从股票池里应该优先做哪些票。
4. 对单只股票该建仓、加仓、减仓还是离场。

本体系不追求“单一神指标”，而是把指标分成分层引擎，最终输出人机协同决策。

## 2. 指标分层

### 2.1 市场情绪层

用于判断全市场风险偏好，决定总仓位上限和出手频率。

核心指标：

- 涨跌家数比：上涨家数、下跌家数、平盘家数、涨跌停数量。
- 连板高度与晋级率：最高连板、2 进 3、3 进 4 成功率。
- 市场成交额：两市成交额、与 5 日均额偏离度。
- 北向资金与主力净流入：作为风险偏好辅助项。
- 炸板率：涨停打开占比，反映追高风险。
- 高位股溢价：昨日强势股次日平均收益。
- 情绪周期位置：冰点、修复、主升、分歧、退潮。

建议输出字段：

- `market_sentiment_score`：0 到 100。
- `market_regime`：冰点 / 修复 / 主升 / 分歧 / 退潮。
- `risk_level`：低 / 中 / 高。
- `max_total_exposure`：总仓位上限。
- `max_new_positions`：新增仓位数上限。

### 2.2 题材热度层

用于决定今天优先交易哪些板块或概念，而不是盲选全市场。

核心指标：

- 题材涨停家数与涨幅中位数。
- 题材成交额增速。
- 新闻催化强度：公告、政策、行业事件、舆情热度。
- 龙头集中度：题材内前 3 只核心股成交占比。
- 板块持续性：过去 3 至 5 个交易日热度斜率。
- 题材扩散度：从龙头到跟风的扩散强弱。

建议输出字段：

- `theme_strength_score`
- `theme_news_score`
- `theme_continuation_score`
- `theme_rank`

### 2.3 个股筛选层

用于构建“每日股票池”。

核心指标：

- 趋势强度：MA20/MA60 多头排列、ADX、斜率。
- 资金行为：量比、换手率、主力净流入、大单净额。
- 形态信号：突破、回踩、二波、平台整理、首阴反包。
- 波动质量：ATR、振幅、实体占比、上影线比例。
- 相对强弱：相对指数超额收益、近 5 日排名。
- 基本过滤：ST、停牌、流动性不足、财务风险。

建议输出字段：

- `technical_score`
- `flow_score`
- `structure_score`
- `relative_strength_score`
- `liquidity_score`
- `pool_score`

### 2.4 交易决策层

用于回答“现在该做什么动作”。

动作定义：

- `BUILD`：首次建仓。
- `ADD`：趋势延续时加仓。
- `HOLD`：继续持有。
- `TRIM`：主动减仓。
- `EXIT`：离场。
- `AVOID`：禁止参与。

建仓信号建议：

- 市场情绪不低于阈值。
- 所属题材进入前 N。
- 个股处于趋势延续或关键突破。
- 量价结构健康，且风险收益比满足约束。

加仓信号建议：

- 首仓后盈利达到阈值。
- 回撤不破关键均线或结构位。
- 板块热度未明显衰减。

减仓/离场信号建议：

- 跌破止损位或结构失败。
- 板块热度快速回落。
- 个股爆量滞涨、高位长上影、负面催化出现。
- 市场情绪进入退潮或高风险区。

### 2.5 风控层

这是商业化产品必须单独建模的一层。

核心指标：

- 单票仓位上限。
- 单日总回撤限制。
- 单日新开仓数量限制。
- 连续亏损保护。
- 黑名单与禁买名单。
- T+1、涨跌停、停牌等 A 股交易约束。

建议输出字段：

- `risk_gate_passed`
- `position_size_pct`
- `stop_loss_pct`
- `take_profit_rule`
- `portfolio_heat`

## 3. 推荐评分模型

建议把单只股票最终得分拆成以下权重，便于后续商业化解释：

### 3.1 MVP 阶段

- 市场情绪分：20%
- 题材热度分：20%
- 技术形态分：25%
- 资金行为分：20%
- 消息催化分：10%
- 风险扣分：5%

### 3.2 成熟阶段

- 市场情绪分：15%
- 题材热度分：20%
- 技术形态分：20%
- 资金行为分：15%
- 相对强弱分：10%
- 消息催化分：10%
- 个股质量分：5%
- 风险扣分：5%

输出结果建议：

```text
total_score = base_score - risk_penalty
```

并给出解释标签：

- 高优先级上车
- 观察回踩机会
- 只可低仓位试错
- 暂不参与

## 4. 每日股票池设计

建议拆成 3 层股票池，而不是一个池子全部混在一起。

### 4.1 市场核心池

定义：当天市场最强主线和龙头股集合。

作用：

- 反映情绪锚点。
- 用于观察市场风格切换。
- 可作为“只看不做”的重点标的。

### 4.2 可交易池

定义：满足流动性、风控、趋势、催化等约束后，允许进入交易决策的股票池。

这是系统每天必须输出的核心池。

字段建议：

- 股票代码
- 股票名称
- 所属题材
- 入池原因
- 信号类型
- 建议动作
- 建议买点
- 止损位
- 目标位
- 风险标签

### 4.3 持仓跟踪池

定义：用户已持仓股票集合，专门用于加减仓和离场建议。

作用：

- 与“可交易池”分离，避免混淆。
- 单独展示浮盈浮亏、持仓热度、风控状态。

## 5. AI 解读要求

AI 不直接替代交易系统，而是承担“解释器”角色。

每条建议都要输出：

- 为什么今天能做或不能做。
- 为什么选这只票而不是别的票。
- 当前动作是什么。
- 如果错了，风险会在哪一步暴露。
- 下一步观察点是什么。

推荐模板：

```text
结论：建议 BUILD
原因：市场处于修复期，机器人概念热度排名第 2，该股出现放量突破并站上 5 日线。
风险：若回落跌破 19.80 且题材热度跌出前 5，建议取消建仓。
后续：若次日缩量站稳，可考虑小幅 ADD；若高开低走并放量，优先 TRIM。
```

## 6. 数据源建议

MVP 可分三层落地：

### 6.1 必需数据

- 日线 OHLCV
- 分时或 5 分钟数据
- 基础股票列表
- 板块映射
- 新闻标题与发布时间

### 6.2 进阶数据

- 龙虎榜
- 主力资金流
- 北向资金
- 公告摘要
- 财务过滤标签

### 6.3 商业化增强数据

- 实时 Level-2
- 舆情情感分析
- 行业研报摘要
- 高质量事件流

## 7. 指标落地优先级

### P0 必做

- 市场涨跌家数
- 涨停/跌停统计
- 成交额变化
- 板块热度排名
- MA 趋势
- 突破/回踩形态
- ATR 止损
- 股票池生成
- 建仓/减仓/离场建议

### P1 应做

- 主力净流入
- 连板高度
- 炸板率
- 新闻催化评分
- 板块持续性评分
- 持仓组合热度

### P2 商业化增强

- 舆情大模型摘要
- 个股事件驱动知识图谱
- 用户风格个性化模型
- 自学习策略评估

## 8. 与当前项目的映射建议

结合当前代码结构，建议这样演进：

- `quant_hunter/scanner.py`：从“单纯信号扫描”升级为“股票池生成引擎”。
- `quant_hunter/decision.py`：从“买卖建议”升级为“市场情绪 + 仓位动作决策引擎”。
- `quant_hunter/recommend.py`：承担评分聚合和 AI 解释摘要。
- `quant_hunter/reports.py`：每天生成股票池、盘前计划、盘后复盘 Markdown 报告。
- `app_qt.py`：新增市场情绪总览、板块热度、每日股票池、持仓动作台。

## 9. 关键原则

- 不要让 AI 直接裸下单，必须先过规则引擎和人工确认。
- 股票池必须先于交易建议生成，交易只从池中发生。
- 市场情绪决定仓位上限，不允许个股信号绕过总风险控制。
- 商业化版本必须提供解释、日志、回溯和可审计能力。
