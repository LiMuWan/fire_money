# 迭代 18 - 盘中提醒面板与文本压缩

## 目标

- 把原本只写入运行日志的主线切换提示，升级成推荐页可见的独立提醒面板。
- 继续减少大段说明文字的视觉占比，让推荐页更像交易工作台。
- 将“盘中监控状态”和“主线推演提醒”解耦，避免状态污染。

## 本轮改动

### 1. 新增盘中提醒面板

- 在每日推荐页新增四类提醒卡：
  - `主线切换`
  - `龙头切换`
  - `策略切换`
  - `动作切换`
- 刷新每日推荐池和交易计划后，提醒卡会同步刷新。
- 如果当前没有发生切换，也会显示稳定状态，不再是一片空白。

### 2. 拆分提醒状态存储

- 原本主线推演提示与盘中监控共用一个状态字典，容易互相覆盖。
- 本轮改为：
  - `monitor_alert_state`：用于盘中监控或个股级监控状态。
  - `path_alert_state`：用于主线、龙头、策略、动作四类路径提醒。

### 3. 压缩说明文本区域

- 对以下文本区增加高度约束，避免吞掉主工作区空间：
  - 主线推演路径
  - 推荐逻辑说明
  - 盘前计划说明
  - 市场情绪说明
  - 持仓建议说明
- 文本区保留，但不再抢占表格、卡片和图像的主视觉空间。

### 4. 最近提醒回写到主线推演路径

- 主线推演路径除了展示 `题材 -> 龙头 -> 个股 -> 动作` 逻辑外，
  现在还会附带最近几条提醒摘要，方便复核主线变化。

## 用户价值

- 用户不必盯运行日志，也能直接在推荐页看到今天盘中结构有没有变化。
- 页面层级更清晰，优先看到卡片、表格和动作面板，再补充阅读说明。
- 后续扩展桌面通知、声音提醒或弹窗提醒时，有了统一的数据来源。

## 验收标准

- 推荐页出现独立的“盘中提醒面板”。
- 主线 / 龙头 / 策略 / 动作切换时，提醒面板状态会变化。
- 没有发生切换时，提醒面板显示稳定状态。
- 推荐页底部文字区相比上一版本更紧凑。
